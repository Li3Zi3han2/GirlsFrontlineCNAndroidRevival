## 安装方法（普通用户）

不需要 Root，也不需要连接电脑长期运行。

1. 下载 APK 和完整的 `.tar` 资源包。
2. 在 Android 设备或模拟器上安装 APK。
3. 首次打开客户端，在资源导入页面选择 `.tar` 文件。
4. 保持应用开启，等待资源导入完成。
5. 进入游戏后，使用**自己的 PC 继承版账号**正常登录。

资源包须存放在 Android 系统文件选择器能够访问的位置（例如 `Download` 文件夹）。客户端通过系统文件选择器读取所选文件，不需要 Frida 或广泛的存储权限。

**请勿先手动解压资源包后直接复制进游戏目录。** 测试包与原日服客户端的包名不同，且较新 Android 版本存在文件归属和访问权限限制；应使用客户端内置的资源导入功能。

## 无 Root 部署（Windows + ADB，可选）

对于使用模拟器或希望从电脑传输资源的用户，测试方案还提供通过 PowerShell 脚本自动安装、启动导入器与传输压缩包的方法。该方式使用临时 ADB 端口转发，由客户端自行解包和校验资源，**不需要将压缩包事先复制到模拟器中**。

在具备 `install_rootless.ps1` 和相关测试文件的目录中执行，例如：

```powershell
./install_rootless.ps1 -Device emulator-5558 -Archive "D:\path\to\com.sunborn.girlsfrontline.jp.tar"
```

将设备序列号和压缩包路径替换为实际值。导入时客户端逐文件计算 SHA-256，并与电脑端的公开资源摘要比对；校验完成后进入游戏。该脚本用于**安装和导入**，游戏正常运行时不需要保持 ADB 连接。

测试包名为 `com.sunborn.girlsfrontline.pt`，不会覆盖原日服包 `com.sunborn.girlsfrontline.jp`。

详细技术说明、冷启动测试及回退方式见 [ROOTLESS_SETUP.md](ROOTLESS_SETUP.md)。

## 空间与数据注意事项

- **存储空间**：现有测试资源约 **12 GB**。新安装建议至少预留 **16 GB** 可用空间；若先将完整压缩包放入模拟器 `Download` 后再导入，建议至少 **28 GB**，以容纳压缩包与解包后的文件。实际需求可能随资源版本变化。
- **中断恢复**：导入过程中保持客户端开启。若导入中断，返回导入页后重新选择压缩包，或重新运行部署脚本；未完成导入前不会进入游戏。
- **账号数据**：导入器只处理压缩包中 `files/Android/` 的公开游戏资源，不导入日服客户端的私有账号数据、`stc` 或 `il2cpp` 缓存。
- **登录会话**：首次需正常输入账号密码。测试版会加密保存会话以供后续恢复；如果其他设备登录导致会话失效，仍需重新登录，不会自动抢回账号。
- **更新与卸载**：同包名、同签名的测试包升级安装可保留已有数据；卸载测试包会删除其会话及已导入资源。请务必保留原始资源包。
